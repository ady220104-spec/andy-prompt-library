# 安迪提示词库 · Chrome 插件

适用：Chrome 116+（Manifest V3，未打包加载）。当前版本：v1.1.5。

## 安装

1. Chrome 地址栏打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选中**本文件夹**（放在任意固定位置即可，不要求 D 盘；移动文件夹后扩展 ID 会变，见「红「!」怎么办」）
4. 工具栏拼图图标 → 在「安迪提示词库」旁点图钉固定；之后点红色「安」图标（或按 `Alt+P`）打开右侧边栏

## 怎么用（最快的一种：不用开侧边栏）

在 ChatGPT / Claude / DeepSeek / 豆包 / Kimi 等任意网页的输入框里，**行首打两个斜杠 `//`**（中文输入法下打两下斜杠出来的 `、、`、全角 `／／` 也算），再打几个字筛选，`↑↓` 选、`Enter` 插入、`Esc` 关闭。`//关键词` 会被整段提示词替换掉。每一行下面有一行灰字正文摘要，不用点开就知道是哪条。

- 为什么是两个斜杠：Claude、Notion 这些网站自己的 `/` 是唤起它们的技能 / 命令菜单，打一个 `/` 会两个菜单一起弹；`//` 谁都不冲突
- `//` 只在行首或空格后触发，网址里的 `//` 不会误弹；查询词最长 200 字，可以包含 `/`（例如 `//PPT/小红书`）
- 想改成打一个 `/`，或者整个关掉：侧边栏 ≡ 菜单里点「网页里唤起」那一项轮换
- 中文输入法选词时的 Enter / Esc / 上下键会交还给输入法，不会误插入

### 第二种：侧边栏

1. 光标点进输入框，`Alt+P` 打开侧边栏（搜索框自动聚焦），打几个字
2. 回车 → 第一条结果直接**插进当前网页的输入框**；或者用鼠标点任意一行

### 填空模板 `{{变量}}`

提示词内容里写 `{{股票名}}`，用的时候（`//` 唤起或侧边栏点行）会先弹出填空框，填完再插入。可带默认值：`{{周期:近一周}}`。填空框里 Enter 跳下一项，最后一项 Enter 直接插入。

注意：纯数字的「名字」不当作变量，例如 `{{16:9}}` 会原样保留；需要变量时请用中文/字母名，如 `{{比例:16:9/3:4/9:16}}`。

### 把正在写的内容存进库

在网页输入框里写好一段提示词，按 **`Ctrl+S`** → 存成一份「待保存草稿」，然后按 `Alt+P`（或点工具栏图标）打开侧边栏，在编辑框里确认保存。网页上选中文字后右键「保存到安迪提示词库」也会走同一套保存流程。

> 为什么不再自动弹侧边栏：Chrome 的 `sidePanel.open()` 只允许在用户手势里调用，网页里的 `Ctrl+S` 消息不带手势，自动打开必然失败。现在如实提示「按 Alt+P 打开侧边栏确认」，不再假装已经弹出。

### 侧边栏里的操作

- 点行 = 插入到当前页输入框（页面没有输入框时自动改为复制到剪贴板）；鼠标停在行上会显示正文预览，不用点开
- 行右侧「▾」展开：看全文、★ 收藏、编辑、删除、只复制不插入；新增 / 编辑框左下角也有「收藏」按钮，录入时就能直接标星
- ★ 收藏 = 置顶：收藏的条目永远在列表最上方「★ 收藏」组里，其余按使用次数自动排，越用越靠前，不用手动排序
- 分类：侧边栏里用「全部分类」下拉切换；新标签页大屏打开时是左侧分类栏
- ≡ 菜单：新标签页大屏编辑、导出 / 导入 JSON、网页唤起方式、紧凑列表 ⇄ 卡片、深浅色、恢复内置（两段式确认）、备份状态
- 删除：点垃圾桶变「确认删除」，3 秒内再点才删，不弹窗
- 窄侧边栏会强制使用紧凑列表；把侧边栏拉宽后才按你保存的卡片/紧凑偏好显示

## 数据在哪

- 提示词存在 Chrome 本地 `chrome.storage.local`，不上传、不联网；卸载插件或浏览器重置会一起清掉
- **自动硬盘备份（可选）**：每次库有变化，3 秒后由本机备份助手写一份到：
  - 默认：**插件文件夹的上一级 / `安迪提示词库-备份`**（例如插件在 `C:\Tools\andy-prompt-library\安迪提示词库-插件`，备份就在 `C:\Tools\andy-prompt-library\安迪提示词库-备份`）
  - 登记时可以用 `-BackupDir` 参数指定别的目录
  - 同一台电脑有多个 Chrome 配置文件（Profile）时，第一个登记的实例用根目录，后续实例写到 `profiles\<实例ID>\`，互不覆盖
  - `最新.json` 最新一份；`每日\日期.json` 每天一份，留 90 天；`条数变少前\` 一次少了 3 条以上时先留底（最多 30 份）
  - 往 `待导入\` 放网页版导出的 JSON，下次备份时助手会把文件交给插件合并；**合并成功后才移动到 `已导入\`**，失败会保留并提示。单文件超过限制时会在界面提示「已跳过」，不会静默丢
  - 依赖电脑装有 Python 3；启动器会自己找（PATH → 常规安装目录 → 微软商店版 → py 启动器），升级 / 重装 / 换位置不用重新登记
  - 备份状态看 ≡ 菜单里的「备份：…」那一行
- 首次安装自动灌入 `seed.json`（109 条）；网页版工具导出的 JSON 可直接导入合并，反之亦然

## 备份状态与红「!」

侧边栏 ≡ 菜单里的「备份：…」会显示四种状态：

1. **备份：正常 · N 条 · 时间** —— 最近一次成功
2. **备份未启用 · 点此检查** —— 还**没有安装/登记**本机备份助手。这种情况下**不会**在图标上显示红「!」，因为这不是错误，只是可选功能没开
3. **备份失败 · 时间 · 点此重试** —— 助手登记过、但这次写盘失败；图标会显示红「!」，鼠标停上去或点状态行看原因
4. **备份：还没跑过** —— 还没有成功记录

如果是「备份未启用 / 备份失败」，按顺序检查：

1. **没登记 / 登记文件被清理工具删了**（提示「备份助手登记文件不见了」）：双击项目根目录的 `修复备份.cmd`（或右键 `backup-host\登记备份助手.ps1` →「使用 PowerShell 运行」）。脚本会自动按当前插件目录推算扩展 ID，不再写死；结尾逐项打印 PASS/FAIL
2. **登记里没有当前插件 ID / forbidden**：插件文件夹被移动或改名后扩展 ID 会变。重新运行一次 `修复备份.cmd` 即可（脚本会自动识别新 ID；也可用 `-ExtId` 手动指定）
3. **启动后立刻退出 / Failed to connect**：登记还在，但 Python 3 被卸载、升级或换了位置。装一个 Python 3（微软商店版也行）后重新登记
4. **备份目录不可写**：检查备份盘/目录是否存在且有权限；也可以在登记时用 `-BackupDir` 换一个目录
5. **换了电脑 / 重装系统**：注册表里的登记没了，重新运行一次 `修复备份.cmd`

修完怎么让红「!」立刻消失：

- `chrome://extensions` 点「刷新」，然后**关掉并重新打开侧边栏**（旧侧边栏还挂着旧代码）
- 右键工具栏图标 →「重新备份提示词库到硬盘」，或打开侧边栏 ≡ 菜单点一下「备份：…」状态行
- 也可以随便复制一条提示词让库变一次，插件会在 3 秒后自动备份

## 权限与隐私

- 「读取和更改所有网站上的数据」：用于在网页输入框里响应 `//` / `Ctrl+S`、把文字写进输入框、右键保存时读取选中文字；只在本机运行，不监听、不上传
- `nativeMessaging`：只用于可选的硬盘备份，与本机 Python 助手通信；不安装助手就不会启动任何本机进程
- `storage` / `unlimitedStorage` / `sidePanel` / `scripting` / `contextMenus` / `clipboardWrite`：分别用于存库、侧边栏、插入、右键菜单、复制回退
- 完整的数据说明见 [PRIVACY.md](PRIVACY.md)

## 发布 / 打包

- 运行 `build-release.ps1` 生成干净的扩展 zip（只含 manifest、js、html、css、seed、icons；会自动排除 `backup-host/`、`.audit/`、文档和测试脚本），输出到 `dist/andy-prompts-v<版本>.zip`
- 发布包不要包含 `%APPDATA%\AndyPromptBackup`、备份目录、注册表信息或任何本机路径
- 本机备份助手需要单独分发（`backup-host/` + `修复备份.cmd`），商店用户按「备份未启用」的说明安装；如果不想维护 Python 助手，也可以不启用备份功能

## 这次修了什么（v1.1.2，2026-11-09）

**数据安全 / 崩溃**

- 修复侧边栏在脏数据下「保存/收藏/删除全部点了没反应」：启动时一次性把归一化结果写回 storage；persist 过滤 null/非对象；老数据缺 id/字段时自动修复，不再永久报「该条目已删除 / 已在另一窗口修改」
- 根数据不是数组时显示可自救的错误页：先导出原始数据，再两段式清空并恢复内置（不再用不可靠的 `window.confirm`）
- 纯标点内容（如「。。。」）不再让标题识别崩溃、保存无反应或整批导入中断
- 编辑中收到网页 Ctrl+S 的草稿时不再覆盖未保存内容；Esc/遮罩关闭第一次只提示，再按一次才放弃
- 空库时「恢复内置」不再被挡住

**交互 / 数据一致性**

- Ctrl+S 如实提示「已存为待保存草稿 · 按 Alt+P 打开侧边栏确认」，不再假装自动打开（Chrome 手势限制）
- 中文输入法选词不再误插入/误提交；`//` 查询支持 `/`、长度上限放宽到 200、支持全角 `／／`；Shift+Tab 不再插入
- 窄侧边栏强制紧凑列表，不再被标签页里的卡片视图带偏
- 恢复内置改两段式；错误 toast 停留时间更长；窗口标题/数量文案更准确

**备份链路**

- 扩展 ID 改为登记脚本自动按插件目录推算，换目录/换电脑不再必然 forbidden
- 登记脚本逐项自检（文件、manifest、注册表回读、allowed_origins、备份目录可写、协议探针），失败非零退出；支持 `-ExtId`、`-BackupDir`、`-DryRun`
- 备份助手协议 v2：待导入**先合并成功再移动**（避免 >1MB 回包或合并失败时丢文件）；单文件过大/过多会提示跳过；多 Chrome Profile 按实例分目录；每日清理/移动异常只记 warning，不再把一次成功备份误判为失败
- 「备份未启用」不再显示红 `!`；真正失败才红；状态额外记录上次成功时间/条数；错误文案区分备份目录不可写、Python 缺失、登记丢失、协议错误
- 启动器跳过微软商店的 `python.exe` 假别名；py.exe 也过滤；候选解释器先验证是 Python 3

**发布工程**

- 新增 `build-release.ps1` 白名单打包、`.gitignore` 排除 `.audit/`、`PRIVACY.md`、本机路径不再写死
- 版本号 1.1.2；Chrome 最低版本改为 116（`sidePanel.open` 的要求）

## 更新插件代码后

`chrome://extensions` 里点该插件的「刷新」按钮，再重新打开侧边栏即可；数据不受影响。
**已经打开的网页要刷新一次**，`//` 唤起和 `Ctrl+S` 才会在那个页面生效（刷新前那页会提示「插件刚更新过，刷新本页后再试」）。
加了新权限后 Chrome 可能把插件临时停用并提示「需要新权限」，点「接受」或重新打开开关即可。
