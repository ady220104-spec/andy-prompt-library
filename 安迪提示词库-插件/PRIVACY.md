# 隐私说明（安迪提示词库）

最后更新：2026-11-09（v1.1.2）

## 一句话

提示词数据默认只保存在你本机的 Chrome 里；只有你主动安装并启用「硬盘备份助手」时，插件才会把整库通过本机进程写到你自己指定的文件夹，不经过任何服务器。

## 插件会接触什么数据

- **提示词库**：标题、正文、分类、收藏、使用次数、最近使用时间，保存在 `chrome.storage.local`。
- **网页输入内容**：为了在网页输入框里响应 `//` 唤起、`Ctrl+S` 保存、把提示词插回输入框，内容脚本会在 http/https 页面运行，但只在以下时机读取输入框内容：
  - 你输入 `//` 或 `、、` 时，读取光标前的文字用于匹配提示词；
  - 你按 `Ctrl+S` 或使用右键菜单保存时，读取当前输入框/选中文字；
  - 你从侧边栏点击「插入」时，向当前输入框写入文字。
  插件不会监听、记录或上传你在网页里输入的其他内容。

## 数据会离开本机吗

不会。本插件没有服务器、没有统计、没有远程接口，也不包含远程代码。

可选的「硬盘备份」是唯一会把整库写到浏览器之外的功能：

- 由你本机安装的 Python 小助手 `backup_host.py` 执行；
- 写到你在运行 `登记备份助手.ps1` 时确定的本机目录（默认是插件目录上一级的「安迪提示词库-备份」；可用 `-BackupDir` 指定）；
- 备份文件是明文 JSON（`最新.json`、`每日/日期.json`、`条数变少前/`），不会上传；
- 如果你不安装/不启用备份助手，插件不会启动任何本机进程。

## 权限用途

| 权限 | 用途 |
|---|---|
| `storage` / `unlimitedStorage` | 保存提示词库与设置 |
| `sidePanel` | 侧边栏界面 |
| `scripting` | 把提示词插入当前网页输入框、右键保存时读取选中文字 |
| `contextMenus` | 右键「保存到安迪提示词库」、右键图标「重新备份」 |
| `clipboardWrite` | 页面没有输入框时改为复制到剪贴板（含旧浏览器回退） |
| `nativeMessaging` | 仅用于可选的硬盘备份，与本机 Python 助手通信 |
| `host_permissions: http/https` | `//` 唤起、`Ctrl+S`、插入需要页面访问；不读取与功能无关的数据 |

## 删除与保留

- 卸载扩展或清除浏览器扩展数据会删除 `chrome.storage.local` 里的提示词库。
- 硬盘备份文件不受浏览器管理，需要你手动删除；备份助手默认只保留最近 90 天的每日文件，`条数变少前` 目录最多保留 30 份。
